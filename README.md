## Instalação e uso local

Com npm instalado na máquina, rode os comandos abaixo

```bash
  git clone https://github.com/samuelmedeirosjs/task-manager
  cd task-manager
  npm i
  npm run dev
```

e acesse a porta local aberta pelo servidor
